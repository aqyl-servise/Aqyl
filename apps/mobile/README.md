# Aqyl для Android

Обёртка Capacitor: приложение открывает прод-сайт `https://aqyl-service.kz`.
Правки на сайте видны в приложении сразу, без нового релиза в Play.

## Что нужно установить (один раз)

Сборка APK требует того, чего нет в обычном окружении разработки веба:

| Что | Зачем | Проверка |
|---|---|---|
| **JDK 17+** | Gradle не собирает на Java 8 | `java -version` |
| **Android Studio** | Android SDK, платформа 35, build-tools | — |
| `ANDROID_HOME` | путь к SDK в переменных среды | `echo %ANDROID_HOME%` |

## Первая сборка

```bash
cd apps/mobile
npm install
npx cap add android      # создаёт каталог android/ (в git не хранится)
npm run sync
npm run build:debug      # APK для проверки на своём телефоне
```

Отладочный APK появится в `android/app/build/outputs/apk/debug/`.
Его можно скинуть на телефон и установить — для проверки перед публикацией.

## Релиз для Google Play

```bash
npm run build:release    # .aab — Play принимает только этот формат
```

Файл: `android/app/build/outputs/bundle/release/app-release.aab`.
Перед первым релизом нужно создать ключ подписи (`keytool`) и **сохранить его
в надёжном месте**: потеря ключа означает невозможность выпускать обновления
под тем же приложением.

## Правило, которое нельзя нарушать

`appendUserAgent: 'AqylApp/Android'` в `capacitor.config.ts` — не косметика.
По этому маркеру `apps/web/lib/platform.ts` прячет в приложении всё, что
предлагает оплату: Google Play требует продавать цифровые товары через Play
Billing (комиссия 15–30%), а наши пакеты оплачиваются через Kaspi. Уберёте
маркер — приложение получит отказ на ревью.

Что при этом видит учитель в приложении: баланс уроков и сообщение
«Уроки закончились» без цен, кнопок и ссылок на покупку.

## Для публикации в Play понадобится

- Аккаунт разработчика **на организацию** (ТОО «Ақыл Корп.»). Личные аккаунты
  с ноября 2023 обязаны перед публикацией провести закрытое тестирование:
  12 тестировщиков, 14 дней подряд. Организации от этого освобождены.
- **D-U-N-S номер** компании — бесплатный, выдаётся до 30 дней.
- Политика конфиденциальности: `https://aqyl-service.kz/privacy` — уже есть.
- Удаление аккаунта: `https://aqyl-service.kz/delete-account` — уже есть,
  Google требует и ссылку, и возможность удалиться из самого приложения.
- Форма Data Safety, возрастной рейтинг, скриншоты, иконка 512×512,
  описание на русском и казахском.
